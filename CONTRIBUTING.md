# How You Can Help

Whether you know how to code or not, there are several ways to contribute to this project. This guide is for anyone.

## Ways to Help

1. **Translate content** — Assamese ↔ English
2. **Report mistakes** — typos, broken links, wrong information
3. **Suggest improvements** — design, content, features
4. **Spread the word** — share it with people who'd find it useful

## 1. Translate Content

The site needs Assamese and English versions of every post and project. If you know one and can read the other, you can translate.

**What you'll do:**

1. Look through `src/content/projects/en/` and `src/content/projects/as/` (or the same for `blog/`)
2. Find a file in `en/` that doesn't have a matching file in `as/` (or vice versa)
3. Copy the file and translate the text inside
4. Save it with the same filename in the other folder

**Example:**
- English version: `src/content/blog/en/my-post.md`
- Assamese version: `src/content/blog/as/my-post.md`

Both files need the same `title`, `description`, etc., but each in its own language.

**Don't worry about perfect grammar** — we'll review and polish together. It's better to have something than nothing.

## 2. Report Mistakes

Spotted a typo? Broken link? Wrong information? Please report it!

1. Open a [new issue](https://github.com/axomiyaindie/axomiyaindie.github.io/issues) on GitHub
2. Describe what's wrong and where you found it
3. If you have the correct version, mention it

You don't need a GitHub account to read the issues, but you do to post one. It takes 30 seconds to create one.

## 3. Suggest Improvements

Have an idea for the design, a feature, or the content?

- Open a [discussion](https://github.com/axomiyaindie/axomiyaindie.github.io/discussions) or
- Post in the [issues](https://github.com/axomiyaindie/axomiyaindie.github.io/issues) with a clear description

Even small ideas matter. If you think the site could be better, say so.

## 4. Spread the Word

The best way to help is to **share this site** with people who might benefit from it. A student in Assam who needs a learning tool. A friend learning tech. Anyone.

---

## How to Get Started (for people who've never done this)

**If you've never used GitHub before**, you can still contribute:

1. **Report a mistake or suggestion:** Go to the [Issues page](https://github.com/axomiyaindie/axomiyaindie.github.io/issues) and click "New issue"
2. **Translate something:** Read the file on GitHub (you can see it in your browser), copy the text into Google Docs or similar, translate it, then share it with the project owner. They'll add it for you.

You don't need to install anything or know any code to help.

## What NOT to do

- Don't paste content from other websites without permission (copyright)
- Don't add sensitive or private information
- Don't add spammy links or ads
- Don't change the site's fundamental structure without discussing it first
