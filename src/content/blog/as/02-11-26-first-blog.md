## মই কিয় এইটো নিৰ্মাণ কৰিলোঁ

বহুত দিনলৈ মোৰ কামবোৰ দেখুৱাবলৈ কোনো এটা নিৰ্দিষ্ট ঠাই নাছিল। মোৰ প্ৰকল্পবোৰ GitHub-ত সিঁচৰতি হৈ আছিল, মোৰ ভাৱনাবোৰ Twitter থ্ৰেডত হেৰাই গৈছিল, আৰু মই এনে এটা ঠাই বিচাৰিছিলোঁ যিটো সঁচাকৈয়ে মোৰ নিজৰ: এলগৰিদম, বিজ্ঞাপন আৰু বিঘিনি-বিপত্তিৰ পৰা মুক্ত।

কিন্তু ইয়াৰ এটা ডাঙৰ কাৰণ আছিল: **ভাষা**।

অসম সংস্কৃতি আৰু ভাষাৰে চহকী, কিন্তু ইণ্টাৰনেট মূলতঃ ইংৰাজী-প্ৰধান। মই এনে এখন ৱেবছাইট সাজিব বিচাৰিছিলোঁ যিয়ে অসমীয়া আৰু ইংৰাজীক সমান মৰ্যাদা দিয়ে। পাছত যোগ কৰা কোনো অংশ হিচাপে নহয়, বা ভুল ব্যাকৰণ দেখুৱাই দিয়া এটা "translate" বুটাম হিচাপেও নহয়, বৰঞ্চ প্ৰথম দিনৰ পৰাই সমান গুৰুত্বৰে।

গতিকে, মই এনে এখন ব্যক্তিগত ৱেবছাইট সাজিবলৈ ল'লোঁ যিয়ে:

- **মোৰ সকলো প্ৰকল্প** এখন পৰিষ্কাৰ আৰু সুবিধাজনক ঠাইত একেলগে তালিকাভুক্ত কৰে।
- **ইংৰাজী আৰু অসমীয়া দুয়োটাতে** প্ৰকৃত URL-ৰ সৈতে কাম কৰে, কোনো সস্তীয়া ট্ৰিক নোহোৱাকৈ।
- **প্ৰকৃত তাৰিখ** দেখুৱায়, যাতে মই প্ৰতিবাৰ "Published on..." বুলি নিজে টাইপ কৰিব নালাগে।
- **স্বয়ংক্ৰিয়ভাৱে ডিপ্লয় হয়** যেতিয়াই মই পুশ কৰোঁ, যাতে মই লিখাত মনোনিৱেশ কৰিব পাৰোঁ, ডিপ্লয়ত নহয়।
- **দ্ৰুতভাৱে নিৰ্মাণ হয়**, কাৰণ ছমাহ লগা এটা ধাৰণা প্ৰায়ে কেতিয়াও সম্পূৰ্ণ নহয়।

## ষ্টেক (আৰু মই ইয়াক কিয় বাছি ল'লোঁ)

মই WordPress-ৰ দৰে গধূৰ CMS নিবিচাৰিছিলোঁ। মই অত্যধিক ভাৰী React Single Page App-ও নিবিচাৰিছিলোঁ। মই বিচাৰিছিলোঁ গতি, সৰলতা, আৰু সাধাৰণ Markdown-ত লিখিব পৰা সুবিধা।

এই ৱেবছাইটটো যিবোৰ ব্যৱহাৰ কৰি চলিছে, সেয়া তলত দিয়া হ'ল।

### ১. Astro: ফ্ৰেমৱৰ্ক

[Astro](https://astro.build) হৈছে মূল ভেটি। মই ইয়াক বাছি ল'লোঁ কাৰণ ই **ডিফল্টভাৱে শূন্য JavaScript** পঠায়। আপুনি এটা পৃষ্ঠা খুলিলে কেৱল সাধাৰণ HTML আৰু CSS পায়: দ্ৰুত, SEO-অনুকূল, আৰু সকলোৰে বাবে সুগম।

মই Astro-ৰ **Content Collections**-ও ব্যৱহাৰ কৰোঁ। ইয়াৰ অৰ্থ, প্ৰতিটো ব্লগ পোষ্ট আৰু প্ৰকল্প কেৱল এটা ফোল্ডাৰত থকা `.md` ফাইল। Astro-এ frontmatter (অৰ্থাৎ `---` ৰেখা দুডালৰ মাজৰ অংশ) পঢ়ে আৰু মোৰ বাবে পৃষ্ঠাবোৰ বনাই দিয়ে।

### ২. Tailwind CSS: ষ্টাইলিং

মই সাধাৰণ CSS-ৰে আৰম্ভ কৰিছিলোঁ, কিন্তু ৱেবছাইটখন ডাঙৰ হোৱাৰ লগে লগে মই custom class-ৰ মাজত হেৰাই গৈছিলোঁ। গতিকে মই **[Tailwind CSS v4](https://tailwindcss.com/)**-লৈ সলনি কৰিলোঁ। ই মোক HTML-তে `bg-meta-blue` বা `text-text-main`-ৰ দৰে utility class ব্যৱহাৰ কৰি ষ্টাইল কৰিবলৈ দিয়ে। ফলত ডিজাইন একে থাকে আৰু কোডবেছ পৰিষ্কাৰ হৈ থাকে।

### ৩. i18n ৰাউটিং: দ্বিভাষিক ইঞ্জিন

এইটো আছিল আটাইতকৈ কঠিন অংশ। মই এনে এটা সৰল JavaScript টগল নিবিচাৰিছিলোঁ যিয়ে লগে লগে লিখা সলনি কৰে। মই বিচাৰিছিলোঁ **প্ৰকৃত, সুকীয়া URL**:

- ইংৰাজী আছে `axomiyaindie.github.io/`-ত
- অসমীয়া আছে `axomiyaindie.github.io/as/`-ত

হেডাৰত এটা ভাষা সলনি কৰা বুটাম আছে, যিয়ে ভাষা সলনি কৰাৰ সময়ত আপোনাক একে পৃষ্ঠাতে ৰাখে (যেনে, `/blog/post-1`-ৰ পৰা `/as/blog/post-1`-লৈ)।

### ৪. GitHub Actions: ডিপ্লয়মেণ্ট পাইপলাইন

মই যেতিয়াই এটা কমিট পুশ কৰোঁ, এটা ৰবট সাৰ পায়। ই ডিপেণ্ডেন্সীবোৰ ইনষ্টল কৰে, ষ্টেটিক ছাইটখন বিল্ড কৰে, আৰু GitHub Pages-ত ডিপ্লয় কৰে। গোটেই প্ৰক্ৰিয়াটোত প্ৰায় ৬০ ছেকেণ্ড সময় লাগে, আৰু মই কেতিয়াও নিজে ডিপ্লয় কৰিব নালাগে।

### ৫. Git Log: স্মাৰ্ট তাৰিখ

মই প্ৰতিটো Markdown ফাইলত `date: "2026-11-02"` বুলি টাইপ কৰিব নিবিচাৰিছিলোঁ। তাত ভুল হোৱাৰ সম্ভাৱনা থাকে, আৰু মই সদায় পাহৰি যাওঁ। ইয়াৰ সলনি মই এটা সৰু Node.js স্ক্ৰিপ্ট লিখিছোঁ যি বিল্ডৰ সময়ত চলে। ই প্ৰতিটো ফাইলৰ প্ৰকৃত Git ইতিহাস চাবলৈ `execSync('git log ...')` ব্যৱহাৰ কৰে:

- যদি ফাইলটোত মাত্ৰ এটা কমিট আছে, ই **"Published on [প্ৰথম কমিটৰ তাৰিখ]"** দেখুৱায়।
- যদি ফাইলটো পিছত আপডেট কৰা হৈছে, ই স্বয়ংক্ৰিয়ভাৱে **"Updated on [শেষ কমিটৰ তাৰিখ]"**-লৈ সলনি হয়।

### ৬. ডিজাইন

ডিজাইনটো **[Meta AI Blog](https://ai.meta.com/blog/)**-ৰ পৰা বহুখিনি অনুপ্ৰাণিত: পৰিষ্কাৰ টাইপগ্ৰাফী (Inter ফণ্ট), প্ৰচুৰ খালী ঠাই, আৰু পঢ়াত সুবিধা। Hero অংশটো এটা custom carousel, যি কেৱল CSS আৰু অলপ vanilla JavaScript-ৰে সজা হৈছে।

### ৭. AI কোডিং সহায়ক: মোৰ সহযাত্ৰী

মই এজন স্বতন্ত্ৰ ডেভেলপাৰ, গতিকে মোৰ কোনো দল নাই। কিন্তু মোৰ কেইটামান AI সহায়ক আছে, যিবোৰে মোৰ এই ধাৰণাটো অলপ সময়তে এখন কাম কৰা ৱেবছাইটলৈ ৰূপান্তৰিত কৰাত সহায় কৰিলে:

- **Claude**: গাঁথনি পৰিকল্পনা, কোড লিখা আৰু পৰীক্ষা কৰা, আৰু লিখনি পালিছ কৰা।
- **ChatGPT**: ভাৱনা-চিন্তা, দ্ৰুত সমাধান, আৰু ভুলৰ বাৰ্তা বুজাই দিয়া।
- **Google Gemini**: আন এটা মতামত, আৰু আটক খালে অন্য এটা দৃষ্টিভংগী।
- **DeepSeek**: অধিক কোডৰ সহায়, আৰু সমাধানবোৰ মিলাই চোৱা।

কেইবাটাও ব্যৱহাৰ কৰাটো কামত আহিছিল, কাৰণ প্ৰতিটোৱে অলপ বেলেগ ধৰণে ভাবে। এটাই দুৰ্বল উত্তৰ দিলে আনটোৱে প্ৰায়ে ভাল উত্তৰ দিছিল।

মই এটা নিয়ম মানি চলিছিলোঁ: **AI-এ খচৰা লিখে, সিদ্ধান্ত মই লওঁ।** মই প্ৰতিটো সলনি পঢ়িছিলোঁ আৰু পৰীক্ষা কৰিছিলোঁ, আৰু সিহঁতে ভুল কৰা কথাবোৰ শুধৰাইছিলোঁ। ধাৰণা, উদ্দেশ্য, আৰু ৱেবছাইটৰ দায়িত্ব মোৰ। AI-এ কেৱল সপ্তাহ লগা কামটো কেইদিনমানতে কৰিবলৈ সম্ভৱ কৰি দিলে।

## মই কি শিকিলোঁ

১. **Linux হৈছে case-sensitive।** `Layout.astro` নামৰ ফাইল Windows-ত ভালদৰে চলে, কিন্তু GitHub Actions-ত আপোনাৰ বিল্ড ভাঙি পেলাব। সকলো সৰু আখৰত (lowercase) ৰাখক।
২. **দ্বিভাষিক ৱেবছাইট কঠিন।** অনুপস্থিত অনুবাদবোৰ সুন্দৰকৈ সামৰা অতি গুৰুত্বপূৰ্ণ, যেনে অন্য ভাষাৰ বিকল্প দিয়া custom 404 পৃষ্ঠাৰ জৰিয়তে।
৩. **স্বয়ংক্ৰিয়তাই সময় ৰাহি কৰে।** Git তাৰিখ আৰু GitHub Actions ছেট আপ কৰাৰ পিছত মই ডিপ্লয়মেণ্টৰ কথা চিন্তা কৰাই বন্ধ কৰিলোঁ।
৪. **AI হৈছে গুণক, বিকল্প নহয়।** আপুনি কি সাজিব বিচাৰে সেয়া জানিলে ই আপোনাৰ গতি বঢ়ায়। সেয়া ই আপোনাৰ হৈ ঠিক নকৰে।

এই ৱেবছাইটখন এটা জীৱন্ত প্ৰকল্প। মই অধিক প্ৰকল্প যোগ কৰি থাকিম, অধিক লিখিম, আৰু প্ৰতিটো পোষ্টৰ অসমীয়া অনুবাদ সম্পূৰ্ণ কৰিম।

যদি আপুনি ইয়াক কেনেকৈ নিৰ্মাণ কৰা হৈছে চাব বিচাৰে, গোটেই কোডবেছ [GitHub](https://github.com/axomiyaindie/axomiyaindie.github.io)-ত মুকলি। ইয়াক fork কৰিবলৈ, অনুবাদ কৰিবলৈ, বা কেৱল হাই ক'বলৈ আপুনি স্বাধীন।
