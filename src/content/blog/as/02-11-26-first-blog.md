## মই কিয় এইটো নিৰ্মাণ কৰিলোঁ

বহুত দিনৰ পৰা, মোৰ নিজৰ কামবোৰ দেখুৱাবলৈ কোনো এটা নিৰ্দিষ্ট ঠাই নাছিল। মোৰ প্ৰকল্পবোৰ GitHub-ত সিঁচৰতি হৈ আছিল, মোৰ ভাৱনাবোৰ Twitter থ্ৰেডত হেৰাই গৈছিল, আৰু মই এনে এটা ঠাই বিচাৰিছিলোঁ যিটো সঁচাকৈয়ে মোৰ নিজৰ—এলগৰিদম, বিজ্ঞাপন আৰু distract-ৰ পৰা মুক্ত।

কিন্তু ইয়াৰ এটা ডাঙৰ কাৰণ আছিল: **ভাষা**।

অসম সংস্কৃতি আৰু ভাষাৰে চহকী, কিন্তু ইণ্টাৰনেট মূলতঃ ইংৰাজী-প্ৰধান। মই এনে এখন ৱেবছাইট নিৰ্মাণ কৰিব বিচাৰিছিলোঁ যিয়ে অসমীয়া আৰু ইংৰাজীক সমান গুৰুত্ব দিয়ে। ইয়াক "translate" বুটাম হিচাপে নহয়, বা অসমীয়া ব্যাকৰণ ভাঙি দিয়া এটা সঁজুলি হিচাপে নহয়, বৰঞ্চ প্ৰথম দিনৰ পৰাই এটা প্ৰথম শ্ৰেণীৰ নাগৰিক হিচাপে গণ্য কৰিব।

গতিকে, মই এনে এটা ব্যক্তিগত ৱেবছাইট সাজিবলৈ ল’লোঁ যিয়ে:
- **মোৰ সকলো প্ৰকল্প** একেলগে এখন পৰিষ্কাৰ আৰু সুবিধাজনক ঠাইত তালিকাভুক্ত কৰে।
- **ইংৰাজী আৰু অসমীয়া দুয়োটাতে** প্ৰকৃত URL-ৰ সৈতে কাম কৰে (কোনো সস্তীয়া CSS ট্ৰিক নহয়)।
- **প্ৰকৃত তাৰিখ** দেখুৱায়, মই প্ৰতিবাৰে "Published on..." বুলি মেনুৱেলি টাইপ কৰিব নালাগে।
- **স্বয়ংক্ৰিয়ভাৱে ডিপ্লয় হয়** যেতিয়াই মই পুছ কৰোঁ, যাতে মই লিখাত মনোনিৱেশ কৰিব পাৰোঁ, ডিপ্লয়ত নহয়।

## ষ্টেক (আৰু মই ইয়াক কিয় বাছনি কৰিলোঁ)

মই WordPress-ৰ দৰে গধূৰ CMS নিবিচাৰিছিলোঁ। মই ফুলি থকা React Single Page App নিবিচাৰিছিলোঁ। মই গতি, সৰলতা, আৰু সাধাৰণ Markdown-ত লিখাৰ ক্ষমতা বিচাৰিছিলোঁ।

এই ৱেবছাইটটো ঠিক কি কি ব্যৱহাৰ কৰি চলিছে:

### ১. Astro (ফ্ৰেমৱৰ্ক)
[Astro](https://astro.build) হৈছে মূল ভেটি। মই ইয়াক বাছনি কৰিলোঁ কাৰণ ই **ডিফল্টভাৱে শূন্য জাভাস্ক্ৰিপ্ট** প্ৰদান কৰে।
যেতিয়া আপুনি এটা পৃষ্ঠা চাবলৈ যায়, ই কেৱল খোলা HTML আৰু CSS। দ্ৰুত, SEO-অনুকূল, আৰু সুগম।

মই Astro-ৰ **Content Collections**-ও ব্যৱহাৰ কৰিছোঁ। ইয়াৰ অৰ্থ হ'ল প্ৰতিটো ব্লগ পোষ্ট আৰু প্ৰকল্প কেৱল এটা ফোল্ডাৰত থকা `.md` ফাইল। Astro-এ frontmatter (অৰ্থাৎ `---` ৰ মাজৰ কথাখিনি) পঢ়ে আৰু মোৰ বাবে পৃষ্ঠাবোৰ সৃষ্টি কৰে।

### ২. Tailwind CSS (ষ্টাইলিং)
মই সাধাৰণ CSS-ৰ পৰা আৰম্ভ কৰিছিলোঁ, কিন্তু ৱেবছাইটটো ডাঙৰ হোৱাৰ লগে লগে মই custom class আৰু inline style-ত ডুব গৈছিলোঁ।
মই সকলো **[Tailwind CSS v4](https://tailwindcss.com/)**-লৈ ৰূপান্তৰিত কৰিলোঁ। ই মোক HTML-ত সোজাকৈ utility class (যেনে `bg-meta-blue` বা `text-text-main`) ব্যৱহাৰ কৰি সকলো ষ্টাইল কৰিবলৈ দিয়ে। ই ডিজাইনটো একে ৰাখে আৰু কোডবেছ অতি পৰিষ্কাৰ কৰি তোলে।

### ৩. i18n ৰাউটিং (দ্বিভাষিক ইঞ্জিন)
এইটো আছিল আটাইতকৈ কঠিন অংশ। মই এনে এটা সৰল জাভাস্ক্ৰিপ্ট টগল নিবিচাৰিছিলোঁ যিয়ে লগে লগে লিখা সলনি কৰে। মই **প্ৰকৃত, সুকীয়া URL** বিচাৰিছিলোঁ।
- ইংৰাজী `axomiyaindie.github.io/`-ত আছে
- অসমীয়া `axomiyaindie.github.io/as/`-ত আছে

মই পৃষ্ঠাবোৰ `as/` ফোল্ডাৰত কপি কৰি আৰু Astro-ৰ内置 i18n ৰাউটিং ব্যৱহাৰ কৰি ইয়াক কৰিলোঁ। হেডাৰত এটা ভাষা পৰিৱৰ্তনকাৰী আছে যিয়ে বুদ্ধিমত্তাৰে আপোনাক একে পৃষ্ঠাতে ৰাখে যেতিয়া আপুনি ভাষা সলনি কৰে (যেনে, `/blog/post-1`-ৰ পৰা `/as/blog/post-1`-লৈ)।

### ৪. GitHub Actions (CI/CD পাইপলাইন)
মই যেতিয়াই GitHub-ত এটা কমিট পুছ কৰোঁ, এটা ৰবট সাৰ পায়।
ই ডিপেন্ডেন্সীবোৰ ইনষ্টল কৰে, ষ্টেটিক চাইটটো বিল্ড কৰে, আৰু GitHub Pages-ত ডিপ্লয় কৰে। গোটেই প্ৰক্ৰিয়াটোৱে প্ৰায় ৬০ ছেকেণ্ড সময় লয়। মই কেতিয়াও মেনুৱেলি চাইটটো ডিপ্লয় কৰিব নালাগে।

### ৫. Git Log (স্মাৰ্ট তাৰিখ)
মই Markdown ফাইলত `date: "2026-11-02"` বুলি মেনুৱেলি টাইপ কৰিব নিবিচাৰিছিলোঁ। ই ভুলৰ প্ৰৱণতা থাকে, আৰু মই সদায় পাহৰি যাওঁ।
ইয়াৰ পৰিৱৰ্তে, মই এটা সৰু Node.js স্ক্ৰিপ্ট লিখিছোঁ যি বিল্ডৰ সময়ত চলি থাকে। ই ফাইলটোৰ প্ৰকৃত Git ইতিহাস চাবলৈ `execSync('git log ...')` ব্যৱহাৰ কৰে।
- যদি ফাইলটোত কেৱল এটা কমিট আছে, ই **"Published on [First Commit Date]"** দেখুৱায়।
- যদি ফাইলটো তেতিয়াৰ পৰা আপডেট কৰা হৈছে, ই স্বয়ংক্ৰিয়ভাৱে **"Updated on [Last Commit Date]"**-লৈ সলনি হয়।

### ৬. ডিজাইন
ডিজাইনটো **[Meta AI Blog](https://ai.meta.com/blog/)** ৰ পৰা অনুপ্ৰাণিত। পৰিষ্কাৰ টাইপগ্ৰাফী (Inter ফণ্ট ব্যৱহাৰ কৰি), প্ৰচুৰ বগা ঠাই, আৰু পঢ়াৰ ওপৰত গুৰুত্ব। Hero অংশটো এটা custom carousel যি খোলা CSS আৰু অলপ vanilla JavaScript ৰ সৈতে নিৰ্মিত।

## মই কি শিকিলোঁ

১. **Linux হৈছে case-sensitive।** `Layout.astro` নামৰ এটা ফাইল Windows-ত ভালদৰে কাম কৰে, কিন্তু GitHub Actions-ত আপোনাৰ বিল্ড ভাঙি দিব। সকলো সৰু আখৰত (lowercase) হ'ব লাগিব।
২. **দ্বিভাষিক ৱেবছাইট কঠিন।** অনুপস্থিত অনুবাদবোৰ সুন্দৰভাৱে পৰিচালনা কৰাটো (custom 404 পৃষ্ঠাৰ সৈতে যি অন্য ভাষাৰ প্ৰস্তাৱ দিয়ে) অতিশয় গুৰুত্বপূৰ্ণ।
৩. **স্বয়ংক্ৰিয়তাই সময় ৰাহি কৰে।** Git তাৰিখ আৰু GitHub Actions ছেট আপ কৰাৰ পিছত, মই ডিপ্লয়মেণ্টৰ কথা একেবাৰে চিন্তা কৰা বন্ধ কৰিলোঁ।

## ইয়াৰ পিছত কি?

এই ৱেবছাইটটো এটা জীৱন্ত প্ৰকল্প। মই অধিক প্ৰকল্প যোগ কৰিম, অধিক চিন্তা লিখিম, আৰু হয়তো অতি সোনকালে এটা সম্পূৰ্ণ অসমীয়া ব্লগ অনুবাদো যোগ কৰিম।

যদি আপুনি ইয়াক কেনেকৈ নিৰ্মাণ কৰা হৈছে চাব বিচাৰে, গোটেই কোডবেছ [GitHub](https://github.com/axomiyaindie/axomiyaindie.github.io)-ত মুকলি। ইয়াক fork কৰিবলৈ, অনুবাদ কৰিবলৈ, বা কেৱল হাই ক'বলৈ স্বাধীন।
